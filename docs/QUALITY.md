## Запуск

Четыре Docker Compose сервиса подняты: PostgreSQL, FastAPI, webhook worker, Next.js. Миграции и seed применяются автоматически; API и PostgreSQL проходят healthcheck. Sandbox данные сохраняются в именованном томе. Ключ конфигурации создаётся bootstrap-скриптом, не входит в Git и архив исходников.

Проверен единый launcher `npm run sandbox` / `python3 infra/run.py`: сборка прошла; после освобождения временного кэша Docker приложение запущено через `--no-build`. В managed workspace frontend слушает `0.0.0.0:3000`, API и PostgreSQL — loopback. Изменение Origin allowlist проверено отдельно: sandbox допускает только известные локальные алиасы с теми же схемой/портом, production сохраняет единственный origin.

## Границы проверки

Реальных списаний нет. Публичная HTTPS-доставка webhook не проверена end-to-end в этой proxy-среде; проверена фактическая HTTP-доставка на фиксированный локальный sandbox receiver, подпись и защита от повтора. Внешний пилот требует проверки egress, нагрузки, отказоустойчивости и независимого security review. Нет утверждений о соответствии PCI DSS, требованиям ЦБ РФ или другим стандартам. Остальные ограничения описаны в [SECURITY](../SECURITY.md) и [ROADMAP](../ROADMAP.md).

## Запуск для macOS

Добавлены `Start AgentPass.command` и `Stop AgentPass.command`: папка определяется по расположению файла; конфигурация генерируется системным OpenSSL; Node/npm/Python на хосте не требуются. Проверены Bash syntax, валидность Fernet-ключа и запуск четырёх настоящих Compose сервисов с проверкой HTTP готовности на текущем Linux окружении. Native macOS/Finder в этом окружении недоступен; двойной щелчок в Finder отдельно не проверен. Архив сохраняет executable bits командных файлов и исключает `.env`/зависимости.
