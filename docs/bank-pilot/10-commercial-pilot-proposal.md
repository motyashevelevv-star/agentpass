# Черновик предложения ограниченного оплачиваемого пилота

Адресат: потенциальный банк или разработчик финансовых AI-агентов. Это проект условий для переговоров; оферта не принята, заинтересованность конкретного банка не предполагается.

Предмет: установка изолированного AgentPass sandbox, интеграция одного согласованного test workflow через одного доверенного исполнителя, совместная проверка полномочий, replay/limits/approval/timeout и отчёт о результатах. Ориентир длительности — 4–6 недель после предоставления доступов, срок подлежит согласованию. Только синтетические данные и тестовые средства.

Результаты: работающий test connector в согласованной сети, OpenAPI/SDK/example, threat model, журнал тестов, измерения согласованных критериев, список production gaps и оценка следующего этапа. Приёмка — по совместно утверждённой версии [критериев](07-pilot-acceptance-criteria.md).

Коммерческие условия: фиксированная оплачиваемая стоимость, этапы/оплата/поддержка и лимиты работ определяются после технического discovery отдельным договором; цена и обещание банковского SLA здесь не выдумываются. Изменение test API или объёма работ требует отдельной оценки.

Интеллектуальная собственность на существующий AgentPass и универсальные доработки сохраняется у владельцев AgentPass. Заказчик получает ограниченное право использования для согласованного пилота; права на специфические deliverables, лицензии сторонних компонентов и дальнейшее коммерческое использование определяются договором. Банковские данные и секреты остаются под контролем заказчика. Условия проверяются юристами обеих сторон.

Не входит: production, реальные списания, формальная сертификация, передача исключительных прав на платформу, бессрочная поддержка и разработка недокументированных банковских API. Go/no-go после пилота — отдельное решение сторон на основе фактических результатов.
