# Входные условия ограниченного пилота

Это предложение AgentPass для обсуждения, а не официальные требования ВТБ.

Со стороны банка/партнёра нужны:

- Технический владелец интеграции, специалисты security/IAM/API и ответственный за приёмку.
- Согласованный use case: кто выдаёт мандат, кто владелец счёта, кто является trusted executor, какой test action разрешён.
- Документированные test API, test credentials, лимиты/retry/idempotency semantics, статусы, callbacks и процедура reconciliation.
- Доверенные идентификаторы продавца, заказа, категории и суммы; источник их проверки.
- Sandbox сеть/egress/TLS, IdP metadata и тестовые пользователи, требования журналирования/retention и доступов.
- Согласованные критерии, окно работ, объём тестовых данных, перечень запрещённых действий и ответственные за инциденты.

Со стороны AgentPass: immutable intent/grant/worker boundary, SDK/OpenAPI/example, regression suite, threat model и список gaps. До предоставления credentials и E2E не заявлять интеграцию с банком. Нужны отдельные согласования юристов и ИБ по данным/ответственности; реальные карты и деньги в этот этап не входят.
